IMPORTANT: You must replace this with a real google-services.json before building!

Steps:
1. Go to console.firebase.google.com -> your SARFIT project
2. Click the gear icon (Project settings) -> scroll to "Your apps"
3. Click "Add app" -> Android
4. Package name: com.mohammedaqeel.sarfitadmin
5. Download the google-services.json it gives you
6. Place it at: app/google-services.json (same folder as this readme, replacing nothing else needed)
7. Delete this readme file (optional)
